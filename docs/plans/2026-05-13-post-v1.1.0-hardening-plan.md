# Post-v1.1.0 Hardening Implementation Plan

> **REVISED 2026-05-13 (rev2)** after `advisor()` review + independent second-AI review. Three speculative tasks deferred to **v1.3.0**, three new tasks added, several path/constant corrections applied. See "Revision Log" below for the exact diff.

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal (rev2):** Close 9 evidence-based production-readiness gaps on the `main` branch (post-v1.1.0): (1) trial state is a raw string outside the `SubscriptionStatus` enum, (2) trial orchestration is missing entirely, (3) `composer.json` artificially requires PHP `^8.4` blocking PHP 8.3 deployments, (4) `json_encode()` based idempotency hashes can collapse on non-UTF8 payloads, (5) four cron queries load full result sets, (6) cancel TOCTOU loser receives `false`, (7) `PaymentCallbackController` has the same `request->all()` and unfiltered-header issues `WebhookController` had pre-v1.1.0, (8) `INSTALLATION.md` documents a non-existent callback URL, (9) six docs are stale relative to v1.1.0.

**Architecture:** Each issue is fixed under TDD with a dedicated regression test in `tests/Feature/PhaseThirteenHardeningTest.php`. Code fixes are non-breaking additive changes — no public API removal. The `'trialing'` raw-string state is promoted into the `SubscriptionStatus` enum so `Subscription::transitionTo()` (which already calls `SubscriptionStatus::normalize()` then `canTransitionTo()`) starts validating instead of silently falling through. JSON-based idempotency hashes are routed through a `Support\Json::safeHash()` helper that handles UTF-8 substitution and JSON encoding failures deterministically. Large cron queries use `lazyById()` to bound memory at any scale.

**Tech Stack:** PHP 8.2/8.3/8.4 (constraint to be relaxed in Task A), Laravel 10/11/12 (illuminate/contracts ^10.0|^11.0|^12.0|^13.0), Pest PHP, PHPStan level 5, libsodium (Ed25519), iyzipay-php, Spatie Laravel PDF, Carbon.

**Branch:** `fix/post-v1.1.0-hardening` (already created from `main` at commit `64c1e4c`).

```php
<?php

declare(strict_types=1);

namespace SubscriptionGuard\LaravelSubscriptionGuard\Support;

final class Json
{
    /**
     * Deterministically hash any value to a 64-char hex SHA-256.
     *
     * Uses JSON_THROW_ON_ERROR + JSON_INVALID_UTF8_SUBSTITUTE to handle
     * binary or invalid-UTF8 inputs without collapsing to hash('sha256','').
     * Falls back to serialize() when JSON encoding still fails (cycles, resources).
     */
    public static function safeHash(mixed $value): string
    {
        try {
            $encoded = json_encode(
                $value,
                JSON_THROW_ON_ERROR
                | JSON_UNESCAPED_SLASHES
                | JSON_UNESCAPED_UNICODE
                | JSON_INVALID_UTF8_SUBSTITUTE
            );
        } catch (\JsonException) {
            $encoded = 'serialize:'.serialize($value);
        }

        return hash('sha256', $encoded);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace SubscriptionGuard\LaravelSubscriptionGuard\Jobs;

use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\DB;
use SubscriptionGuard\LaravelSubscriptionGuard\Enums\SubscriptionStatus;
use SubscriptionGuard\LaravelSubscriptionGuard\Models\Subscription;
use SubscriptionGuard\LaravelSubscriptionGuard\Payment\PaymentManager;
use SubscriptionGuard\LaravelSubscriptionGuard\Subscription\SubscriptionService;

final class ProcessTrialExpiryJob implements ShouldQueue
{
    use Dispatchable;
    use InteractsWithQueue;
    use Queueable;
    use SerializesModels;

    public function __construct(public int|string $subscriptionId)
    {
        $this->onQueue((string) config('subscription-guard.queue.queue', 'subguard-main'));
    }

    public function handle(PaymentManager $paymentManager, SubscriptionService $subscriptionService): void
    {
        $lock = Cache::lock('subguard:trial-expiry:'.$this->subscriptionId, 30);

        if (! $lock->get()) {
            $this->release(5);

            return;
        }

        try {
            DB::transaction(function () use ($paymentManager, $subscriptionService): void {
                $subscription = Subscription::query()->lockForUpdate()->find($this->subscriptionId);

                if (! $subscription instanceof Subscription) {
                    return;
                }

                if ((string) $subscription->getAttribute('status') !== SubscriptionStatus::Trialing->value) {
                    return;
                }

                $trialEndsAt = $subscription->getAttribute('trial_ends_at');

                if ($trialEndsAt === null || $trialEndsAt->isFuture()) {
                    return;
                }

                $provider = (string) $subscription->getAttribute('provider');
                $providerManaged = $provider !== '' && $paymentManager->managesOwnBilling($provider);

                if ($providerManaged) {
                    return;
                }

                if ($subscriptionService->applySubscriptionStatus($subscription, SubscriptionStatus::PastDue, 'trial.expired')) {
                    if ($subscription->getAttribute('grace_ends_at') === null) {
                        $subscription->setAttribute(
                            'grace_ends_at',
                            now()->addDays((int) config('subscription-guard.billing.grace_period_days', 7))
                        );
                    }

                    $subscription->save();
                }
            });
        } finally {
            $lock->release();
        }
    }
}
```

```php
public function cancelSubscription(string $subscriptionId): bool
{
    if (! $this->mockMode()) {
        if ($subscriptionId === '' || $this->missingCredentials() !== []) {
            return false;
        }

        try {
            $request = new SubscriptionCancelRequest;
            $request->setConversationId('iyz_cancel_'.bin2hex(random_bytes(8)));
            $request->setSubscriptionReferenceCode($subscriptionId);

            $response = SubscriptionCancel::cancel($request, $this->options());

            if ($this->isSuccessfulResponse($response)) {
                return true;
            }

            $errorCode = method_exists($response, 'getErrorCode') ? (string) $response->getErrorCode() : '';
            $errorMessage = strtolower($this->responseError($response, ''));

            if ($this->isAlreadyCancelledError($errorCode, $errorMessage)) {
                return true;
            }

            return false;
        } catch (Throwable) {
            return false;
        }
    }

    return $subscriptionId !== '';
}

private function isAlreadyCancelledError(string $errorCode, string $errorMessage): bool
{
    $alreadyCancelledCodes = ['1', '200001', '200002']; // iyzico subscription-not-found / already-cancelled codes
    $alreadyCancelledFragments = ['not found', 'already cancelled', 'already canceled', 'cancelled before'];

    if (in_array($errorCode, $alreadyCancelledCodes, true)) {
        return true;
    }

    foreach ($alreadyCancelledFragments as $fragment) {
        if (str_contains($errorMessage, $fragment)) {
            return true;
        }
    }

    return false;
}
```
